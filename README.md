# Energy Shield Mod

A functional energy shield mod for Minecraft with customizable features.

## Features

- Creates an energy shield around the player
- Toggle the shield with a keybind or by crouching twice
- Shield has a lifetime of 60 seconds

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.15.7 or later
- Fabric API

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/energy-shield-mod/releases).
2. Place the mod file in your `mods` folder.
3. Launch Minecraft with Fabric.

## Usage

- Press the default keybind (not yet assigned) to toggle the energy shield.
- Crouch twice to toggle the energy shield.

The mod does not have a configuration file yet, but future updates may include customizable settings.
